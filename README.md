# Spotify Music Recommendation System 🎧

## 📌 Overview

This project demonstrates a **music recommendation system** using Spotify track data. It uses audio features to recommend similar songs based on their characteristics.

The entire implementation is contained in a **Jupyter Notebook**, including data processing, model building, and results.

---

## 📁 Project Contents

* `Spotify_Music_Recommendation.ipynb` → Main notebook with complete workflow and outputs

---

## 🚀 What This Project Does

* Analyzes Spotify audio features (e.g., energy, tempo, danceability)
* Computes similarity between songs
* Recommends songs similar to a given track
* Displays results directly within the notebook

---

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/deepayans/Spotify-Music-Recommendation-System.git
cd Spotify-Music-Recommendation-System
```

2. Install dependencies:

```bash
pip install pandas numpy scikit-learn matplotlib seaborn jupyter
```

3. Launch Jupyter Notebook:

```bash
jupyter notebook
```

4. Open the notebook file and run all cells
